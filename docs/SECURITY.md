# الأمن وحماية البيانات

| الضابط | التنفيذ |
|---|---|
| HTTPS | يُنهى عند وكيل عكسي (Nginx/Caddy)؛ `COOKIE_SECURE=true` و`TRUST_PROXY=1`؛ HSTS عبر helmet |
| كلمات المرور | Argon2id، سياسة 10+ حرفًا حروف وأرقام، تجزئة وهمية لمعادلة الزمن، إعادة تجزئة تلقائية |
| الدخول | حد 20 محاولة/15 د لكل IP + قفل الحساب 15 د بعد 5 فشل؛ رسالة موحدة؛ تجديد الجلسة عند الدخول؛ مستخدم جديد يُجبر على تغيير كلمته |
| الجلسات | تخزين في PostgreSQL، `HttpOnly`، `SameSite=Lax`، `Secure`، 8 ساعات متجددة |
| CSRF | رمز مرتبط بالجلسة في ترويسة لكل طلب مغيّر + فحص `Origin` + SameSite |
| الصلاحيات | RBAC من الخادم على كل نقطة؛ تُقرأ حديثًا من قاعدة البيانات؛ الحقول المالية تُحذف من الاستجابات لمن لا يملك `payments.view` |
| SQL Injection | استعلامات مُعلَّمة فقط؛ الفرز بقائمة بيضاء؛ هروب LIKE |
| XSS | الواجهة لا تستخدم innerHTML (بناء DOM آمن)؛ CSP صارمة (`script-src 'self'`)؛ PDF بلا JS وبلا شبكة |
| الرفع | PDF/PNG/JPG فقط بفحص البصمة الثنائية، 5MB، أسماء عشوائية خارج الجذر العام، تنزيل عبر API بصلاحية، `nosniff` + CSP sandbox، حذف منطقي |
| التدقيق | `audit_logs` إضافة فقط (مشغّلات تمنع UPDATE/DELETE/TRUNCATE) داخل نفس معاملة العملية؛ الجوال/البريد مقنَّعان؛ لا أسرار |
| الأسرار | في متغيرات البيئة فقط؛ `.env` مُستبعد من git؛ لا كلمات مرور افتراضية |

## PDPL (نظام حماية البيانات الشخصية)
- **تقليل البيانات:** تُجمع بيانات الاتصال والعضوية فقط؛ لا هوية وطنية.
- **الوصول:** بحسب الدور؛ مستندات الأعضاء وإيصالاتها بصلاحيات منفصلة؛ التصدير بصلاحية ويُدقَّق.
- **الاحتفاظ:** لا حذف تلقائي؛ الأرشفة تُخفي دون حذف. **يلزم قرار قانوني** لمدد الاحتفاظ وحقوق الحذف/التصحيح لأصحاب البيانات وسجل معالجة وإشعار الأعضاء. ملفات الاستيراد المؤقتة تُحذف بعد الاعتماد.
- النسخ الاحتياطية تحوي بيانات شخصية: شفّرها وقيّد الوصول إليها (انظر OPERATIONS).

## مخاطر معروفة
- `exceljs` يعتمد على `uuid` القديم (GHSA-w5hq-g745-h8pq: يتطلب تمرير `buf` يدويًا وهو غير مستخدم هنا) — لا استغلال قابل للتحقق؛ تابع تحديث exceljs.
- لا مصادقة ثنائية (MFA) بعد؛ يُنصح بها لدور مدير النظام والمالي.
- لا فحص برمجيات خبيثة للمرفقات (فحص بصمة النوع فقط).
- ينبغي إجراء اختبار اختراق مستقل قبل النشر العام.
