# ملخص الاختبارات ومعايير القبول

النتيجة عند آخر تشغيل: `npm test` → **66 ناجح / 0 فاشل** (≈6 ث)، و`npm run test:e2e` → **جميع خطوات الواجهة ناجحة بلا أخطاء كونسول**.

| # | معيار القبول | الاختبار (`test/platform.test.js` ما لم يُذكر غير ذلك) |
|---|---|---|
| 1 | إضافة عضو واسترجاعه | «السيناريو 1–2» + e2e `add member via modal` |
| 2 | تعديل دون فقدان السجل | «التعديل يحتفظ بالدورات والمدفوعات ويسجل التدقيق» + e2e `edit member keeps history` |
| 3 | دفعة جزئية والمتبقي | «السيناريو 3–4: دفعة جزئية…» (بما فيها كسور 100.10/199.90) |
| 4 | دفعات متعددة | «دفعات متعددة لنفس الاشتراك» + السباق المتزامن (4 طلبات متوازية → واحد ينجح) |
| 5 | حالة العضوية بالتواريخ والقواعد | «السيناريو 5–6» (حد 30/31 يومًا، السماح، شرط التفعيل، التعليق/الإلغاء) |
| 6 | حالة السداد مستقلة | «منتهي لكنه مسدد»، «ساري لكنه متأخر»، غير مستحق/غير مسدد/جزئي، الإعفاء |
| 7 | تجديد دون حذف السابق | «السيناريو 7» (دورتان، الاشتراك القديم ومدفوعاته باقية، منع التداخل، عضوية ملغاة) |
| 8 | مؤشرات = قاعدة البيانات | «السيناريو 8» (مقارنة مباشرة بـ SQL مستقل + تطابق عدد أعضاء كل مؤشر) + e2e `kpi drill-down` |
| 9 | تصدير Excel وPDF صحيح | «السيناريو 9» (قراءة xlsx: RTL، خلايا رقمية/تاريخية، مجموع يطابق JSON؛ PDF يبدأ بـ `%PDF-`) + e2e `report export downloads` |
| 10 | منع غير المصرح من المدفوعات | «السيناريو 10» (viewer/membership/finance، 401، CSRF، إخفاء الحقول المالية، تعديل الأدوار) |
| 11 | سجل التدقيق | «السيناريو 11» (المستخدم، قبل/بعد، التقنيع، منع UPDATE/DELETE/TRUNCATE) |
| 12 | استيراد مع أخطاء وتكرار | «السيناريو 12» (أرقام الصفوف، تكرار الملف/القاعدة، تأكيد صريح، رصيد افتتاحي، منع اعتماد مزدوج) + e2e `import flow via UI` |

إضافي: التطبيع (جوال/مبلغ/تاريخ)، المرفقات (ملف تنفيذي بامتداد صورة، >5MB، تنزيل بصلاحية)، التنبيهات (idempotent، تعطيل نوع)، القفل بعد المحاولات الفاشلة، حماية آخر مدير، سياسة كلمة المرور، فرض تغييرها، الإعدادات وأنواع العضوية، حقن SQL في البحث والفرز، الجوال (بلا تمرير أفقي)، الوضع الداكن، وعدم ظهور أزرار الكتابة للمشاهد.

## ما لم يُختبر
حمل/أداء بآلاف الأعضاء، متصفحات غير Chromium، قارئات الشاشة فعليًا (روعيت الدلالات: `aria-*`، تركيز، تباين)، النسخ الاحتياطي/الاستعادة على بيئة حقيقية، HTTPS خلف وكيل، اختبار اختراق مستقل.
